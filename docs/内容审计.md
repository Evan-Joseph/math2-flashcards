## 逐卡修正（示例）

- `pre`「反函数」：原文「单调函数必有反函数」改为「**严格单调**函数必有反函数」，补充「有反函数不一定单调」的反例，并说明连续函数下二者等价；求导公式补 $f'(x)\ne0$ 条件。
- `h3` 基本积分表：$\int\frac{dx}{\sqrt{a^2-x^2}}$、$\int\sqrt{a^2-x^2}\,dx$ 补 $a>0$、$|x|<a$（$\le a$）与 $\arcsin$ 主值支；$\int\frac{dx}{\sqrt{x^2-a^2}}$、$\int\sqrt{x^2-a^2}\,dx$ 补 $|x|>a$（$\ge a$）；$\int\frac{dx}{x^2-a^2}$ 补 $x\ne\pm a$；$\int\ln x\,dx$ 补 $x>0$，$\int\arcsin x\,dx$ 补 $|x|<1$。
- `h4` 二元极值：必要条件补「偏导存在」，充分条件补「二阶连续偏导」。
- `h4` / `extra` 拉格朗日乘数法：补 $f,\varphi$ 一阶连续偏导与约束正则性 $\nabla\varphi\ne\mathbf 0$，多约束时梯度线性无关。
- `h6` 伯努利方程：补 $n\ne0,1$、$y\ne0$ 与 $y\equiv0$ 解，范围改为仅数一。
- `l1` 行列式公式：补方阵要求、$|A^{-1}|$ 需可逆、$|A^*|=|A|^{n-1}$ 对 $n\ge2$ 任意方阵成立、$|A|=\prod\lambda_i$ 计重数含复根。
- `l2` 逆矩阵运算律：补「同阶可逆、$k\ne0$」；伴随矩阵三组公式分别补「任意方阵 / 需可逆 / $n\ge2$」。
- `l5` 特征值表：补 $\alpha\ne\mathbf 0$，$A^{-1}$、$A^*$ 行的 $\lambda\ne0$ 条件。
- 挖空渲染：`plain` 模式下挖空内容改为花括号分组，修复 `\le⟦r(A)⟧` 之类拼接为未定义控制序列的问题（由 `check:data` 对全部 3400+ 条公式做 `throwOnError` 渲染验证）。

## 新增内容的核验方式

所有新增数一卡片的公式均按同济 / 浙大教材通行表述编写，并在卡片 `cond` 字段写明定义域、参数范围、方向 / 侧 / 单连通等适用条件；`check:data` 保证数一专属讲次（30 讲第 16–18 讲、概率分册）只被 `scope: 'm1'` 卡片引用。

## 2027 大纲发布后的复核流程

1. 对照新大纲逐章比对 `src/data/index.ts` 的 `ref`；
2. 有变动的知识点先改 `status: 'pending'`（自动退出默认队列），确认后再恢复；
3. 运行 `npm run verify`。

## 本轮迭代（知识点聚合与状态口径）

### 知识点聚合（`src/data/knowledge.ts`）

同一知识点的主卡与增补卡（`-x` 系列）、不同题型 / 表述共用一个稳定的 `kid`，统计中的「唯一知识点数」按 `kid` 去重；「卡片数」「复习次数」「掌握状态」分别独立计算：

- 卡片数：进入队列的卡片张数（数二 291 / 数一 378）
- 唯一知识点数：按 `kid` 去重（数二 256 / 数一 343）
- 复习次数：来自日志的评分次数，与卡片数无关
- 知识点掌握状态：取该知识点全部卡片中最弱者；「稳固」要求全部卡片稳定性 ≥ 21 天

逐组核对（31 组）：`pre.curves`（pre-13 / x01 / x02）、`pre.inequalities`、`fn.parity-transfer`（h2-29 与 pre-x04）、`lim.heine`、`lim.procedure`、`lim.infinite-vs-unbounded`、`lim.closed-interval`、`lim.diff-equivalents`、`diff.curvature`、`diff.auxiliary-fn`、`diff.taylor`、`diff.root-count`、`int.arc-length-surface`（h3-28 / h3-x01 / h3-x02 / h2-x02 弧微分）、`int.wallis`、`int.physics`（含形心 h3-x04）、`int.p-integral`、`mv.relations`、`mv.differentiable-test`、`mv.lagrange`、`mv.second-order-chain`、`dbl.symmetry`、`dbl.polar-limits`、`dbl.swap-order`、`ode.reducible`、`ode.homogeneous-const`、`ode.reverse`、`ode.modeling`、`la.orthogonal`、`la.rank-props`、`la.similar-test`、`la.orth-diag`。

未合并的「同主题不同结论」示例：弧微分与微分近似（h2-33 / h2-x03 相关变化率）、一阶方程识别顺序（h6-x04，策略卡）与各类一阶方程解法。
