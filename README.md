# 考研数学识记 · 数学一 / 数学二

面向长期备考的公式、定理与易错点主动回忆应用：**先回忆，后揭示**，按 FSRS 间隔复习；支持数学一 / 数学二两种考试模式、随机 / 顺序两种出题方式、填空逐空揭示、判断、选择、分步提示、相似知识点辨析、收藏、笔记、搜索、真实统计、导入导出与离线使用（PWA）。

全部数据只保存在浏览器本机（localStorage），没有账号、后端或云同步。

## 学习方式

- **今日任务**：到期复习 + 每日新卡上限内的新卡，评分 忘了 / 模糊 / 记住 / 轻松 写入 FSRS（`ts-fsrs`），答错的卡片至少间隔 3 张后再次出现。
- **随机模式（默认）**：跨章节交错、避免相邻重复；**顺序模式**：按知识库顺序，首页可续学。
- 卡片类型：问答（回忆后显示）、填空（点空或按空格逐空揭示）、判断（Y / N）、选择（A–D）、步骤（逐步提示）。提示（记忆锚点）可先于答案查看。
- 章节学习 / 顺序通读、薄弱点、收藏、单卡自测、检索结果自测；自测不写入调度与统计。
- 键盘：`空格` 显示 / 下一空，`1–4` 评分，`H` 提示，`F` 收藏，`U` 撤销，`I` 详情，`Esc` 退出，自测中 `←/→` 翻页。

## 技术

Next.js 16（App Router）+ React 19 + Tailwind CSS 4 + KaTeX + ts-fsrs + motion。无数据库、无服务端 API 依赖（`/api/health` 为静态健康检查）。

```bash
npm install
npm run dev
```

### 校验

```bash
npm run lint            # ESLint
npm run typecheck       # tsc
npm run check:data      # 数据完整性、数一/数二过滤、待确认不进队列、3400+ 条公式 KaTeX 渲染
npm run check:render    # 挖空三态互斥、逐空揭示、表格 / 步骤 / 块级公式结构、全部卡片正反面渲染
npm run check:schedule  # FSRS 调度、撤销、模式切换、随机 / 顺序、重排、导入导出、旧数据迁移
npm run verify          # 以上全部 + 生产构建
```

### 部署

- **Vercel**：直接导入仓库，零配置（`npm run build`）。
- **Cloudflare Pages**（纯静态）：构建命令 `npm run build:static`，输出目录 `out`。`public/_headers` 已为 `sw.js` 关闭缓存。
