# 考研数学识记学习应用

当前根目录是 V1.0 Vite + React + GSAP 前端，保留其移动端交互和动画基线，供后续继续优化。

## 知识资料

- `src/data/`：当前 V1.0 应用数据
- `knowledge-base/v2/src/data/`：V2.0 数学一/数学二扩展数据、来源和内容审计资料
- `knowledge-base/v2/docs/`：V2.0 页码索引、内容审计和验收清单
- `01_教材与讲义/`：教材、课程与页码索引
- `02_材料索引.md`：本地材料来源与核验状态

后续修改必须以 V2.0 的知识审计结果为准确性基线，同时保留或进一步提升 V1.0 的响应式、动效和交互体验。

## 开发

```bash
npm install
npm run dev
npm run build
npm run preview
```

构建产物为 `dist/`，可直接部署到 Cloudflare Pages 或 Vercel。
