# Math Flashcards

考研数学识记与间隔复习项目，当前源码由 ZIP 导入，备考资料与大纲索引保留在原有目录中。

## 项目结构

- `src/`：Next.js 应用源码与数学卡片数据
- `public/`：静态资源与 PWA 配置
- `01_教材与讲义/`：教材、课程和页码索引
- `02_交互可视化/`：历史交互可视化项目
- `02_材料索引.md`：材料来源与核验状态
- `00_学习状态.md`：当前数学学习状态

## 运行

```bash
npm install
npm run dev
```

构建检查：

```bash
npm run lint
npm run typecheck
npm run build
```
