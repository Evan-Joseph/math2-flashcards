# 数学学习记录归档（当前按数学二）

本目录保存用户提交的手写作答和批改扫描件，按日期分目录归档。

- 原始 PDF 原样保存，不覆盖、不改写。
- 文件名注明材料、范围和证据性质，如“首次作答”“批改稿”。
- 扫描件只证明页面中可见的作答、批改或备注，不自动证明正确率、订正完成或掌握。
- 正文、题号和标准答案仍以实体书或仓库中的原始教材 PDF 为准。
- 本目录只保存本地原始附件，不建立平行的结构化学习账本；attempt、error、correction、recall 和 review 的结构化索引仍只写入 study-ledger。
- 用户作答扫描件保持本地忽略，不提交或上传；仓库只跟踪本说明文件。
